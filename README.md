# PalindroneChecker
 A program to detect palindrones written in x86-64 Assembly.

To run, compile and link the program using NASM - The Netwide Assembler. Information on how to do so can be found on the NASM website:\
[https://www.nasm.us/](https://www.nasm.us/)\\
To change the word you'd like to check, alter the checkWord variable inside of palindrone.asm\
I will soon update this to ask for input via a C program so that it will be more "user friendly." (Whatever that means..)\\

This program is written to function in UNIX ONLY, so no windows build yet. :(
